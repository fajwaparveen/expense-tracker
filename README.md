# Pocketwise: Expense Tracker

A simple expense tracker built with React and TypeScript.

## Features
- Add expenses with a description, amount and category
- Edit and delete existing expenses
- Live total that updates instantly
- Input validation with clear error messages
- Data saved in the browser, so it stays after a refresh
- Amounts shown in Indian Rupees (₹)

## Built with
- React
- TypeScript
- CSS
- Browser localStorage

## What I learned
- Managing state with React hooks (useState, useEffect, useMemo)
- Building create, read, update and delete (CRUD) features
- Handling forms and validation
